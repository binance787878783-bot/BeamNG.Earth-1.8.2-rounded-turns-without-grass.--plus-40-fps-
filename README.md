An unofficial experimental build of BeamNG.Earth 1.8.2-beta.

### Features
- Smooths sharp corners on paved roads.
- Removes grass and other vegetation for improved performance.
- Provides an average performance increase of approximately **40 FPS**. Actual results may vary depending on your PC, settings, and location.

### Installation
Download and extract the ZIP archive. Keep the files together, then run `Launch BeamNG.Earth with Rounded Turns.cmd` with Steam open.

### Status
Road geometry tests have passed. This build has not yet been fully tested during an in-game drive.

This is an unofficial community modification of BeamNG.Earth. It is not an official release from TecnaGamer or BeamNG GmbH. The archive includes the original license and credits.
